# Master's Thesis – Automating the Linking of Touristic Data Using Excel, GIS, and Python

**Authors:** Peter Carney, Thijs De Bock , Vivienne Chen   
**Institution:** KU Leuven  
**Year:** 2025

This master's thesis was conducted by a team of three and investigated how data matching techniques can improve the accuracy and reliability of regional tourism statistics.

The rapid growth of platforms such as Airbnb has created large amounts of accommodation data that are not always adequately represented in official tourism statistics. This research addresses that gap by developing a methodology to link accommodation listings from **Inside Airbnb** with official data from **Tourism Flanders**

### Research Question

*How can data matching techniques enhance the real-world validity and reliability of tourism statistics for the Flanders region?*

### Methodology

A multilevel data-matching methodology was developed using geospatial variables and unique identifiers to link records across the two datasets.

The matching process was evaluated using a three-class classification framework:

- **Matched:** Records successfully linked across datasets.
- **Missed:** Records identified as missing from the corresponding dataset.
- **Inconclusive:** Records for which a reliable match could not be established.

The resulting matches were used to estimate unaccounted accommodation capacity and derive a potential correction factor for regional tourism statistics.

### Technologies & Methods

- **Python:** Data processing, automation, and matching.
- **GIS:** Geospatial analysis and distance-based matching.
- **Excel:** Data exploration and validation.
- **Data matching:** Record linkage using unique identifiers and geographical information.
